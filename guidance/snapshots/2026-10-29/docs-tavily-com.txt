Claude & Claude Code
ChatGPT & Codex
Cursor
OpenCode
Claude Code
claude mcp add tavily --transport http https://mcp.tavily.com/mcp/
Claude (claude.ai, Claude Desktop, and Cowork): click Add to Claude , then Connect , and sign in to Tavily. Claude Code : run the command above; Claude Code opens your browser to sign in to Tavily when you start a new session. See the Claude guide for the Tavily plugin and organization-wide access.
Codex
codex mcp add tavily --url https://mcp.tavily.com/mcp/
codex mcp login tavily
Click Add to ChatGPT and Codex to open the Tavily plugin, then connect it and sign in to Tavily. To use the MCP server in Codex instead, run the commands above. See the MCP guide for other options.
mcp.json
{
"mcpServers" : {
"tavily" : {
"url" : "https://mcp.tavily.com/mcp/"
}
}
}
Click Add to Cursor and sign in to Tavily when Cursor prompts you, or add the server to ~/.cursor/mcp.json yourself. For the recommended plugin setup, standalone options, and examples, see the Cursor guide .
Terminal
opencode.json
curl -fsSL https://cli.tavily.com/install.sh | bash
tvly login
{
"$schema" : "https://opencode.ai/config.json" ,
"plugin" : [ "opencode-tavily" ]
}
Paste the setup prompt into OpenCode to let it set Tavily up, or install the Tavily CLI, sign in, and add the opencode-tavily plugin to your opencode.json . OpenCode installs the plugin on next launch. See the OpenCode guide for details.

Make your first API call
Get a free Tavily API key (1,000 API credits every month, no credit card required), install an SDK, and replace tvly-YOUR_API_KEY with your key.
Python
JavaScript
cURL
# pip install tavily-python
from tavily import TavilyClient
tavily_client = TavilyClient( api_key = "tvly-YOUR_API_KEY" )
response = tavily_client.search( "Who is Leo Messi?" )
print (response)
// npm i @tavily/core
const { tavily } = require ( "@tavily/core" );
const tvly = tavily ({ apiKey: "tvly-YOUR_API_KEY" });
const response = await tvly . search ( "Who is Leo Messi?" );
console . log ( response );
curl -X POST https://api.tavily.com/search \
-H "Content-Type: application/json" \
-H "Authorization: Bearer tvly-YOUR_API_KEY" \
-d '{"query": "Who is Leo Messi?"}'
